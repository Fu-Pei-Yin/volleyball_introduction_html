# 排球介紹網站（Volleyball Introduction）

> HTML5 WEB APP 程式設計課程期末報告｜以多頁式網站整理排球的歷史、規則、職責與站位，並整合 Google 試算表、Google 表單與站位模擬工具。

**線上展示：** <https://html5-final-report.netlify.app/>

---

## 摘要（Abstract）

排球的規則與站位牽涉位置編號、輪轉方向與球員分工。這些內容用純文字很難說清楚。

本專案以 HTML5 建置一個八頁式介紹網站。內容包含排球的起源與發展、男女排差異、球員職責、三種常見的陣容配置與國際賽事資訊。網站另有兩項互動功能：賽事資料表，資料直接讀取自 Google 試算表，可排序與搜尋；站位模擬，使用者輸入兩隊球員與職責後，系統把名單標示在球場圖上。

## 研究動機（Motivation）

作者有實際參與排球隊的經驗，並擔任系女排隊長。

排球的入門資料多半分散在不同網站。位置編號、輪轉規則、陣容配置各成一塊，初學者要自己拼湊。因此本專案把這些內容整理在同一個網站，並用圖片與互動工具輔助理解。

## 主要功能（Features）

### 1. 多頁式導覽

頂部導覽列與側邊欄（Materialize Sidenav）連結八個頁面。頁尾另有各章節的錨點連結。手機寬度下，點擊內容區會自動收合側邊欄。

### 2. 賽事資料表

賽事資料存放在 Google 試算表的「國際賽事」工作表。頁面載入時，透過 Google Visualization Query 讀取資料，再動態產生表格。

- 表格套用 DataTables，支援排序、搜尋與分頁，介面為繁體中文。
- 預設依第一欄遞減排序。
- 第三欄的內容自動連結到 Google 地圖搜尋。

這樣做的好處是：更新賽事只需要改試算表，不必修改網頁。

### 3. 站位模擬

使用者依序輸入：

1. 兩支隊伍的名稱。
2. 每隊一至六號位的球員姓名。
3. 每位球員的職責，可選主攻手、副攻手、舉球員、自由球員。

按下送出前，系統會先跳出確認視窗。確認後，名單依位置編號顯示在球場圖的對應位置。

畫面上的「球員資訊查詢」按鈕，可輸入隊伍名稱或球員姓名。查詢隊伍會列出六個位置的姓名與職責，查詢球員會顯示所屬隊伍、站位與職責。輸入不存在的名稱，系統回報「輸入錯誤」。

### 4. 使用者回饋

回饋頁面要求使用者選擇建議頁面並填寫內容，兩項皆為必填，缺漏時會跳出提示。驗證通過後，資料以預填網址的方式送到 Google 表單。

## 限制與未來工作（Limitations and Future Work）

**限制**

- 站位模擬只做「名單標示」，不會自動輪轉。使用者需要自行重新輸入輪轉後的名單。
- 球員位置的座標以固定像素寫在程式中，畫面寬度改變時，名字可能偏離球場圖上的位置。
- 回饋以預填網址開啟新視窗的方式送出，而不是在頁面內直接傳送。
- 本 repo 未包含樣式表資料夾（`css/`）與部分圖片檔（例如球場圖）。直接在本機開啟時，版面與圖片可能不完整。完整效果請看線上展示。

**未來工作**

- 加入自動輪轉功能：每按一次，全隊依順時針方向移動一個位置，並標示發球員。
- 以相對座標或 SVG 重繪球場，讓位置在各種螢幕寬度下維持正確。
- 以非同步方式送出回饋，並在頁面內顯示送出結果，不再開啟新視窗。
- 補齊 `css/` 與圖片資源，讓本機也能完整執行。
