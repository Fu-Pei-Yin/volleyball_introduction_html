# 排球介紹網站（Volleyball Introduction）

> HTML5 課程期末報告｜以多頁式網站整理排球的歷史、規則、職責與站位，並提供站位模擬工具。

**線上展示：** <https://html5-final-report.netlify.app/>

---

## 摘要（Abstract）

排球的規則與站位輪轉不易靠文字理解。初學者常卡在「為什麼要輪轉」和「誰站在哪裡」。

本專案以 HTML5 建置一個多頁式介紹網站。內容涵蓋排球的起源與發展、男女排差異、球員職責、三種常見站位配置與賽事資訊。網站另附站位模擬頁面，讓使用者直接操作，觀察輪轉後的位置變化。

## 研究動機（Motivation）

作者長期參與排球運動，並擔任系女排隊長。實務上，新隊員最常問的就是站位與輪轉。口頭講解費時，圖文資料又分散各處。

因此把這些問題集中成一個網站。目標很單純：讓第一次接觸排球的人，也能自己看懂一場比賽。

| --- | --- | --- |

## 主要功能（Features）

- **多頁式導覽：** 側邊選單與頁尾連結，可直接跳到各章節錨點。
- **圖片輪播：** 首頁以橫向切換呈現排球相關圖片。
- **站位模擬：** 使用者操作球員位置，觀察輪轉結果。
- **回饋機制：** 表單分頁面收集建議，作為後續修改的依據。
